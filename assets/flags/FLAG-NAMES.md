# National team flag filenames

Drop image files into this folder named exactly as listed below.
Supported formats: `.png` (recommended), `.svg`, `.jpg`, `.webp`

```
assets/flags/england.png
assets/flags/cote-d-ivoire.png
```

Any nation without an image gets a generated monogram, so you can add as
many or as few as you like. Flags are drawn to fill their tile, so a 4:3 or
3:2 source looks best — roughly 128px wide is plenty.

Accented and punctuated names are folded to plain ASCII: **Türkiye** becomes
`turkiye`, **Côte d'Ivoire** becomes `cote-d-ivoire`, **Curacao** becomes
`curacao`. When in doubt, the filename is always the name below.
