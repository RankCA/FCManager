# Club badge filenames

Drop image files into this folder named exactly as listed below.
Supported formats: .png (recommended), .svg, .jpg, .webp
Example:  assets/badges/liverpool.png

Any club without an image automatically gets a generated monogram crest,
so you can add as many or as few as you like.
